# Connect Your Learning Frontend

React frontend for the Connect Your Learning video collaboration app.

## Scripts

From this directory, run:

- `npm start` - start the development server.
- `npm run build` - create a production build.
- `npm test` - run the test suite.

## Main Screens

- Landing page with branded app positioning.
- Auth page for sign in and sign up.
- Home dashboard for joining meetings.
- History page for previous meetings.
- Resume page for personal profile, skills, projects, and PDF preview.
